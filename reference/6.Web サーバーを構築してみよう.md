## コマンド集

### カスタムデータ

仮想マシン作成画面の「詳細」タブにある「カスタムデータ」に貼り付けます。

```bash
#!/bin/bash
apt-get update
apt-get install -y nginx
```

### Cloud Shell

`<PUBLIC_IP>` は仮想マシンの「概要」メニューに表示されるパブリック IP アドレスに置き換えます。

```bash
# 秘密鍵がアップロードされたことを確認する
ls -l

# 秘密鍵の権限を変更する
chmod 400 sshkey-vm.pem

# SSH で接続する
ssh -i sshkey-vm.pem azureuser@<PUBLIC_IP>

# Cloud Shell のグローバル IP アドレスを確認する
curl https://api.ipify.org

# nginx の状態を確認する
systemctl status nginx

# Web ページを取得する
curl http://<PUBLIC_IP>

# 接続を切断する
exit
```
