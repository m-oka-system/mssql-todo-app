## コマンド集

- `<VM01_PUBLIC_IP>` は仮想マシン vm01 の「概要」メニューに表示されるパブリック IP アドレスに置き換えます。
- `<LB_PUBLIC_IP>` はロードバランサーの「概要」メニューに表示されるフロントエンド IP アドレスに置き換えます。

### 基本リソースの作成

```bash
# デプロイ先リソースグループを指定する (コース内ラボ環境では不要)
export TF_VAR_resource_group_name="rg-iaas"

# 基本リソースをデプロイする
curl -fsSL https://raw.githubusercontent.com/m-oka-system/mssql-todo-app/refs/heads/main/labs/sections/section09/setup.sh | bash
```

### 負荷分散の動作確認

```bash
# ロードバランサー経由で繰り返しアクセスして 2 つの VM に振り分けられていることを確認する
curl http://<LB_PUBLIC_IP>/health
```

### vm01 の nginx を停止

```bash
# vm01 に SSH 接続する
ssh -i ~/.ssh/sshkey-vm.pem azureuser@<VM01_PUBLIC_IP>

# nginx を停止する
sudo systemctl stop nginx
sudo systemctl status nginx # Active: inactive (dead)

# SSH 接続を切断する
exit

# ロードバランサー経由で繰り返しアクセスして vm02 にのみ振り分けられていることを確認する
curl http://<LB_PUBLIC_IP>/health
```

### vm01 の nginx を起動

```bash
# vm01 に SSH 接続する
ssh -i ~/.ssh/sshkey-vm.pem azureuser@<VM01_PUBLIC_IP>

# nginx を起動する
sudo systemctl start nginx
sudo systemctl status nginx # Active: active (running)

# SSH 接続を切断する
exit

# 十数秒待ってから、ロードバランサー経由で繰り返しアクセスして 2 つの VM に振り分けられていることを確認する
curl http://<LB_PUBLIC_IP>/health
```
