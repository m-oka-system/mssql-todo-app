# 補足資料

**動画を見ながら手元で使う資料です。** セクションごとに 1 ファイルを置き、動画で実行したコマンドと、公式ドキュメントへのリンクをまとめます。

**カリキュラムの確定にあわせて追加します。**

| ---------- | -------- | ------------ |
| —          | —        | —            |

## 各ファイルの構成

見出しを 4 つに統一します。

| 見出し                       | 内容                                       |
| ---------------------------- | ------------------------------------------ |
| このセクションについて       | 何を扱う回か。1〜2 段落                    |
| コマンド集                   | 動画で実行したコマンド                     |
| 参考サイト                   | 一次情報へのリンク                         |
| **動画公開後の補足・変更点** | ポータルの表示名の変更、手順が変わった箇所 |

**4 つ目は差分の受け皿です。** 動画は撮り直せませんが、Azure ポータルの画面は変わります。**食い違いをここに集約すれば、1 か所を見れば済みます。**

### コマンドに添えること

- どこで実行するか（Cloud Shell・SSH 接続した VM・ブラウザ）
- `<VM_NAME>` のように置き換える箇所
- 成功したときに表示される内容
- よくあるエラーと、最初に確認する箇所

### 参考サイトの書き方

Microsoft Learn などの一次情報を優先します。**リンクだけでなく「このページのどこを読むか」を 1 文で添えます。**

## ファイル名の付け方

```text
reference/
├── README.md                              # 本書
├── sectionNN.<セクション名>.md            # セクションごとの本文
└── assets/
    └── sectionNN/                         # 画面写真・配布ファイル
```

**セクション名は Udemy のコース画面の表記をそのまま使います。** 受講者が動画の一覧と資料を照合できます。

**番号はゼロ埋めします**（`section01` から `section10`）。GitHub のファイル一覧は文字列順のため、ゼロ埋めしないと 10 セクション目以降で順序が崩れます。

**画面写真と配布ファイルは `assets/sectionNN/` へ置きます。** 本文からは `assets/section05/probe.png` のような相対パスで参照します。
