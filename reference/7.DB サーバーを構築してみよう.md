## コマンド集

SQL Database の「クエリエディター」で実行します。

```sql
-- テーブルを作成する
CREATE TABLE todos (id INT IDENTITY(1,1) PRIMARY KEY, title NVARCHAR(255) NOT NULL);

-- テーブルにデータを挿入する
INSERT INTO todos (title) VALUES ('Todo1');
INSERT INTO todos (title) VALUES ('Todo2');
INSERT INTO todos (title) VALUES ('Todo3');

-- テーブルを表示する
SELECT * FROM todos;
```
